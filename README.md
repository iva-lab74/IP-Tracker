# Frontend Mentor - IP address tracker

![Design preview for the IP address tracker coding challenge](./design/desktop-preview.jpg)


## The challenge

- The challenge is to build out this IP Address Tracker app and get it looking as close to the design as possible. To get the IP Address locations, you'll be using the [IP Geolocation API by IPify](https://geo.ipify.org/). To generate the map, we recommend using [LeafletJS](https://leafletjs.com/).

Your users should be able to:

- View the optimal layout for each page depending on their device's screen size
- See hover states for all interactive elements on the page
- See their own IP address on the map on the initial page load
- Search for any IP addresses or domains and see the key information and location

## Reflection
- This is the IP Tracker challenge, using HTML, CSS, JavaScript, the IPify API, and LeafletJS. Firstly, I started with the HTML and made the outline for the webpage. After that I worked on the CSS, using flexbox and CSS Grid. Lastly I did the JavaScript, made the methods for the API data. Deployed on Netlify.
- The biggest challenge for me was figuring out how to work the API, key and netify. I had to do my research and see whats out there to help me. I put the API key in a secret file, and was able to keep it confidential. After loading it up on Netify, I had to depend on the console, for my debugging.
- If I had more time, I would add more errors. I would also try to make the page save, if it gets refreshed the page would stay the same. It instantly goes back to default. I would also do more pseudocode, a detailed brainstorm can help the project go smoother. Overall, I learned so much with project, and discovered things I didnt know before.
